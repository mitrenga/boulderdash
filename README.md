BOULDER DASH (Atari 8-bit, 1984) — remake
=========================================

**Internal project.** Boulder Dash® and Rockford® are trademarks of BBG
Entertainment GmbH. This remake is not published, not distributed and not
deployed anywhere public. It exists to be the first real consumer of the
Atari 8-bit platform in the **svision** library and to prove the
`dump*` → `trace*` → `match*` method on a 6502 machine.

**Status: M0–M6 done (2026-09-19), M7 not started.** The cave lives: the
grid is generated by the original's own algorithm (`app/caveGen.js`), the
pass over it is the original's `$1D8F` with every object handler read out
of its code (`app/caveScan.js`), and the per-frame step of its vertical
blank — clocks, birth countdown, window scroll, animation — is
`app/caveFrame.js`. All of it is proved against the running original by
`tools/tracescan.py` (a small 6502 harness planted in the program's memory)
and `tools/matchscan.mjs`: M4 — 143 recordings of all 20 caves × 5
difficulties, 80,524 passes, 84.8 million checks, 0 differences. M5 adds
the game around the cave (`app/caveRules.js`: the original's main loop
`$28F3` — the bonus for the time left, lives and two players taking
turns, intermissions with their bonus life, OUT OF TIME, GAME OVER, the
random covering of the picture, the demo), proved on whole recorded games
by `tools/tracerules.py` (BRK hooks) and `tools/matchrules.mjs`: 16 games,
87 caves, 1.27 million checks, 0 differences. The sound (M6) is the
original's own writes into POKEY, played by the chip model of svision
and proved write by write (`tools/matchsound.mjs`: 6 záznamů, 22 jeskyní, 2 880 průchodů, 38 235 snímků + 3 675 snímků hudby titulky, 77 357 zápisů do POKEY, 4 280 218 kontrol, 0 rozdílů). Left for
M7: polish.

M0: The program is identified
(three independent images agree), the original runs headless in `atari800`
with frame-exact stepping, its display lists, cave table and cadence are
measured, the User's Guide is transcribed and a traced disassembly covers
the code the first cave exercises. Nothing of the remake itself exists yet.
See `ZADANI.md` (what is measured ★ and what is still a guess ?) and
`MILNIKY.md` (milestones with `match*` acceptance).

## Running it

1. `config/config.php` out of `config/config.php.sample` (`$devMode = true`)
2. the disk image into `sources/diskette/`, `atari800` from apt, then
   `./tools/dumpcaves.py`, `dumpcharset.py`, `dumptexts.py`, `dumpglobal.py`
   to regenerate `data/*.json` (they are committed, so this is optional)
3. serve the directory with nginx + PHP; the browser loads `app/` directly

Checks: `tools/tracecavegen.py` (~60 s, 100 runs of the original) then
`tools/matchcavegen.mjs`; `tools/tracescan.py` (all 20 caves × 5
difficulties, `--script idle`, `--scenario magicwall,amoebabox`; ~12 min
on 5 emulators) then `tools/matchscan.mjs` (~10 min) and
`tools/scancoverage.mjs`; `tools/matchcaves.mjs`, `tools/matchcharset.mjs`,
`tools/tracerules.py` (whole games: `--plan exit:t20,die,…`, `--players 2`,
`--demo`) then `tools/matchrules.mjs` (~1 min); `tools/timerules.py` (the
cadence of the cave's end without hooks);
`tools/runworker.mjs`, `tools/matchscreen.mjs` (three screen references,
two of them with a scrolled window), `../svision/tools/checkatari8.mjs`.
`tools/fitpasscost.mjs` refits the pass cadence model from
`matchscan.mjs --costs`.

directory; see `sources/README.md`.
